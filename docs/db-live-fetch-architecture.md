# خطة تنفيذ ميزة سحب قاعدة البيانات الحية (Live Database Fetch)

## الهدف:
سحب قاعدة بيانات User Manager (ملف `sqldb`) من راوتر المايكروتك مباشرة وتحديث الملف المحلي في مجلد التطبيق لتمكين التصفح اللحظي.

## المعمارية التقنية:
سيتم دمج الميزة ضمن `DbExplorerViewModel` باتباع الخطوات التالية:

### 1. الاستعانة بـ FtpWebRequest (مدمج في .NET)
بدلاً من إضافة مكتبات خارجية، سنستخدم `System.Net.FtpWebRequest` المتوفرة في إطار عمل .NET والتي تدعم بروتوكول FTP بالكامل للاتصال بالمايكروتك.

### 2. خطوات التنفيذ البرمجية (Workflow):
1. **استرداد بيانات الاتصال**: سيقوم الـ ViewModel بقراءة الـ IP واسم المستخدم وكلمة المرور من `ISettingsService`.
2. **الاتصال بالمايكروتك (FTP)**: سنقوم بتشكيل عنوان الـ URI ليصبح: `ftp://<Host>/disk1/user-manager/sqldb` (أو المسار المحدد).
3. **التحميل الآمن (Safe Download)**:
   - سنقوم بتحميل الملف كـ Stream.
   - سيتم حفظه أولاً في ملف مؤقت (مثلاً `sqldb.tmp`).
   - بمجرد اكتمال التحميل بنجاح، سيتم استبدال الملف القديم بالملف الجديد (لضمان عدم تلف القاعدة في حال انقطاع الاتصال أثناء التحميل).
4. **تحديث الواجهة (UI Refresh)**:
   - بعد الاستبدال الناجح، سيقوم النظام تلقائياً بإعادة تشغيل دالة `InitializeAsync` لإعادة تحميل البيانات وعرض الأرقام الجديدة.

### 3. تعديلات واجهة المستخدم (UI/XAML):
- إضافة زر جديد بارز في شريط أدوات `DbExplorerPage.xaml` يحمل اسم **"سحب القاعدة حياً من المايكروتك"**.
- ربط الزر بأمر `FetchLiveDatabaseCommand` الذي سيشغل شريط التقدم (IsBusy).
